# docs/GROWTH_SYSTEM.md

## Purpose

The Growth System turns CreatorOS from a drafting tool into a personal operating layer for improving the owner’s X profile and writing ecosystem.

## Core Objects

- Growth goals.
- Content pillars.
- Account positioning.
- Audience hypotheses.
- Weekly strategy.
- Monthly strategy.
- Campaigns.
- Experiments.
- Target accounts.
- Engagement opportunities.
- Content gaps.
- Topic opportunities.
- Profile audits.

## Growth Dashboard

Shows:

- Goal progress.
- Active campaigns.
- Current experiments.
- Publishing cadence.
- Reply cadence.
- Blog cadence.
- X-to-blog conversion.
- Blog-to-X conversion.
- Top growth-moving content.
- Profile audit warnings.
- Recommended next action.

## Campaigns

Campaign fields:

- Name.
- Objective.
- Content pillar.
- Hypothesis.
- Start/end date.
- Target metrics.
- Included content.
- Cadence.
- Result.
- Decision.

Campaign item types:

- X post.
- X thread.
- Reply.
- Quote post.
- Blog post.
- Blog-to-X series.

## Experiments

Experiment types:

- Hook experiment.
- Topic experiment.
- Format experiment.
- Posting-time experiment.
- CTA experiment.
- Reply strategy experiment.
- Blog repurposing experiment.

Each experiment tracks:

- Hypothesis.
- Start/end date.
- Included content.
- Metrics.
- Result.
- AI interpretation.
- Decision: continue, stop, iterate, scale.

## Weekly AI Growth Review

Inputs:

- Past week publishing.
- Metrics and velocity.
- Campaigns.
- Experiments.
- Blogs.
- Replies.
- Missed scheduled posts.
- Failed jobs.
- Ideas backlog.

Outputs:

- What moved growth.
- What did not.
- Best next posts.
- Best next blog.
- Engagement targets.
- Experiment recommendations.
- Warnings.
- Evidence citations.

## Monthly Strategy Review

Outputs:

- Strategic position update.
- Pillar performance.
- Audience hypothesis updates.
- Campaign decisions.
- Profile optimization recommendations.
- Topics to stop/double down.
- Next month content plan.

## Profile Audit

Analyze:

- Bio.
- Header image notes/manual snapshot.
- Avatar/manual snapshot.
- Pinned post.
- Recent post grid.
- Link/call-to-action.
- Positioning clarity.

Outputs:

- Score.
- Findings.
- Recommendations.
- Suggested pinned post drafts.

## Acceptance Criteria

- Owner can define goals/pillars/campaigns/experiments.
- AI can produce weekly/monthly reviews with evidence.
- Experiments can be linked to content and results.
- Campaign performance is visible.
- Recommendations distinguish fact/inference/speculation.
